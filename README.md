# The Daily Pour Café – Wholesale Website 🍵

## Live Demo

https://christinecdev.github.io/dcp-wholesale/

A fictional café wholesale website built with HTML5 and CSS3 as part of my front-end web development journey through FreeCodeCamp.

## Overview

The Daily Pour Café Wholesale is a responsive, multi-page website designed to showcase the café's wholesale products and provide businesses with a convenient way to browse products and prepare bulk orders.

The project focuses on creating a cohesive wholesale shopping experience through consistent branding, reusable CSS components, responsive layouts, and carefully structured pages.

## Features

* Responsive Multi-page Website
* Home page
* About Us page
* How It Works page
* Shopping Cart
* Product cards and category sections
* Cart layout with quantity controls and order summary
* Checkout layout with order details and customer information form
* Responsive navigation and page layouts
* Consistent café branding and visual identity
* Semantic HTML5 structure
* Shared CSS stylesheet
